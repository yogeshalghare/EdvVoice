# Deliberately unpinned.
#
# Exact pins look safer but age badly: a pin that predates your Python
# version sends pip off to compile the package from source, which fails on a
# machine with no Rust toolchain. Python 3.14 hit exactly that with pydantic.
#
# These libraries follow semantic versioning and the code here uses their
# stable APIs, so tracking current releases is the lower-risk option.
# If you ever need to freeze what works, run:  pip freeze > requirements.lock
